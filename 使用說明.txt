==============================================================
  AutoCAD 自動標註程式  使用說明
  檔案：autocad_auto_dim.py / start_autodim.bat / autodim_toggle.lsp
==============================================================

一、這個程式能做什麼
--------------------------------------------------------------
1. 一邊畫圖一邊自動標註
   - 線          → 長度標註（放在圖形外側）
   - 兩條相接的線 → 角度標註（90 度預設不標）
   - 圓          → 直徑 Ø + 十字中心線
   - 弧          → 半徑 R（大於 180 度的弧才畫中心線）
   - 點          → X、Y 座標
   - 聚合線      → 每一段的長度、轉角角度
   - 立體(3D實體) → 外框的長、寬、高
2. 刪掉物件時，它的標註會一起刪掉；修改、縮放、移動後會重新標註。
3. 開啟圖檔時自動把整張圖標好。
4. 工程圖式標註（ADVIEWS）：像課本零件圖那樣，
   孔位置用串連尺寸、相同的孔寫成 2XØ4、相同圓角只標一次 R5，
   文字會自動避開彼此和圖形線。
5. 會自動建立圖層：
   - AUTO_DIM ：所有自動標註（綠色）
   - 中心線   ：自動中心線（紅色，CENTER 線型）
   - 虛線     ：HIDDEN 線型，設為目前圖層就能畫虛線


二、安裝（只要做一次）
--------------------------------------------------------------
1. 需要：Windows + 完整版 AutoCAD（AutoCAD LT 不能用）
2. 安裝 Python：https://www.python.org/downloads/
   安裝時一定要勾「Add Python to PATH」
3. 打開「命令提示字元」(cmd)，輸入：
       pip install comtypes
4. 建立資料夾 C:\autodim\，把下面三個檔案放進去：
       autocad_auto_dim.py
       start_autodim.bat
       autodim_toggle.lsp
5. 在 AutoCAD 輸入 APPLOAD，載入 C:\autodim\autodim_toggle.lsp
   （想每次自動載入：APPLOAD 視窗裡的「啟動程式集」→ 加入這個檔案）


三、每天使用的步驟
--------------------------------------------------------------
1. 先打開 AutoCAD。
2. 雙擊 C:\autodim\start_autodim.bat
   → 會出現一個黑色視窗，畫圖時「不要關掉它」。
3. 回到 AutoCAD 開圖或畫圖：
   - 開啟圖檔：整張圖會自動標好
   - 新畫的東西：畫完（按 Enter 結束指令）就會自動標註
4. 要停止程式：在黑色視窗按 Ctrl+C，或直接關掉黑色視窗。
5. 標好的圖記得自己存檔（程式不會覆蓋你的原檔）。


四、AutoCAD 裡的指令（需先載入 autodim_toggle.lsp）
--------------------------------------------------------------
   ADOFF    暫停自動標註（暫停時畫的東西，恢復後不會補標）
   ADON     恢復自動標註
   ADSW     暫停 / 恢復 切換
   ADVIEWS  整張圖改成「工程圖式標註」（會先清掉之前的自動標註再重標）

   另外，在黑色視窗按 P 也可以暫停 / 恢復。

   建議畫零件圖的流程：
     ADOFF  →  畫完整張圖  →  ADVIEWS


五、在 cmd 直接執行（進階用法）
--------------------------------------------------------------
先切到程式資料夾：
       cd /d C:\autodim

   python autocad_auto_dim.py
       只標註「之後新畫的」物件
   python autocad_auto_dim.py --all
       開啟或切換到的每張圖，整張都標（start_autodim.bat 就是這個）
   python autocad_auto_dim.py "C:\圖\零件.dwg"
       開啟圖檔 → 全部標註 → 另存成「零件_標註.dwg」→ 繼續監看
   python autocad_auto_dim.py "C:\圖\零件.dwg" --once
       同上，但標完就結束（可以一次給好幾個檔案）
   python autocad_auto_dim.py --views
       對目前圖面做工程圖式標註後結束（等同 ADVIEWS）
   python autocad_auto_dim.py "C:\圖\零件.dwg" --views
       讀圖檔做工程圖式標註並另存

   其他參數（可以和上面的一起用）：
     --text 3.5   固定標註字高為 3.5
     --now        不等指令結束，畫一段就標一段
     --no-save    讀圖檔標註後不要另存
     -v           顯示詳細訊息（出問題時用）
     --diag       檢查 AutoCAD 連線狀態（回報問題用）

   注意：圖檔路徑有空格或中文時，前後要加雙引號 "…"


六、畫組合件時避免重複標註
--------------------------------------------------------------
1. 先輸入 ADOFF 暫停，畫完再 ADON。
2. 圖層名稱用 NODIM 開頭（例如 NODIM_零件A），上面的東西一律不標。
3. 零件做成圖塊（BLOCK）再插入，圖塊裡的東西不會被標。
4. 完全重疊的線、同位置同大小的圓，只會標一次。


七、可以調整的設定（用記事本打開 autocad_auto_dim.py，改檔案開頭）
--------------------------------------------------------------
   SIZE_BY_OBJECT = True     False：全部用同一個字高
   NORMAL_SIZE = 200.0       物件大於這個大小，字才會放大
   LINE_OFFSET = 2.5         長度標註離線多遠（字高的倍數）
   DIM_ANGLES = True         False：不標角度
   SKIP_RIGHT_ANGLE = True   False：90 度也標
   DRAW_CENTERLINES = True   False：不畫中心線
   ARC_CENTERLINE_MIN_DEG = 180   弧大於幾度才畫中心線（360 = 弧都不畫）
   VIEW_SEGMENTS = False     ADVIEWS 時是否標每段線長
   VIEW_EACH_ARC = False     ADVIEWS 時 True = 每個弧都標 R
   VIEW_OVERALL = False      ADVIEWS 時是否另外標總長、總高
   LABEL_LEADERS = (2, 4, 7, 11, 16)   圓/弧引線長度候選，擠的話調大
   SKIP_LAYERS = set()       不標的圖層，例如 {"組合件", "標準件"}
   SAVE_SUFFIX = "_標註"     另存檔名的後綴

   標註字高本身：在 AutoCAD 的 DIMSTYLE（標註型式）改文字高度，程式會跟著用。


八、常見問題
--------------------------------------------------------------
Q：出現「找不到執行中的 AutoCAD」
A：先開 AutoCAD 再執行；AutoCAD LT 不支援。

Q：'python' 不是內部或外部命令
A：Python 沒裝好，重裝並勾選「Add Python to PATH」。

Q：No module named comtypes
A：在 cmd 執行 pip install comtypes

Q：can't open file ... autocad_auto_dim.py
A：沒有先 cd /d C:\autodim，或檔案不在那個資料夾。

Q：出現 FutureWarning ... Python 3.15 的警告
A：只是警告，不影響使用；想消除可以改裝 Python 3.13。

Q：中心線或虛線看起來是實線
A：在 AutoCAD 調整 LTSCALE（例如 0.5 或 2）。

Q：標註字太大或太小
A：用 --text 指定字高，或在 DIMSTYLE 改文字高度。

Q：舊的標註沒有跟著圖形變
A：程式只追蹤「這次執行時」畫的標註。用 --all 重開圖，
   或輸入 ADVIEWS，會先清掉舊標註再重標。

Q：「讀取 AcDbArc … 失敗，略過」
A：某個弧讀不到。在 AutoCAD 輸入
       (sssetfirst nil (ssadd (handent "那個handle")))
   找出那個弧，刪掉重畫即可。

Q：想把所有自動標註刪掉
A：刪除 AUTO_DIM 圖層和「中心線」圖層上的所有物件。


九、目前的限制
--------------------------------------------------------------
- 公差（H7、+0.2）、表面粗糙度、倒角 1X45° 需自己補。
- 圖塊（BLOCK）、雲形線（SPLINE）裡的東西不會標。
- 剖面圖的 Ø（兩條平行線）不會自動判斷。
- 標註文字會避開其他標註和圖形線，但尺寸線本身可能還會交叉，
  圖很密時可能需要手動微調。
- 程式關掉再開，之前的標註不會跟著圖形連動（重新 ADVIEWS 即可）。
