# AutoCAD 自動標註 (AutoLISP)

`autodim.lsp`（UTF-8，AutoCAD 2021+）／`autodim_big5.lsp`（Big5，舊版 AutoCAD）內容相同。
用 `APPLOAD` 載入，或把檔案拖進 AutoCAD 視窗。

## 指令

| 指令 | 功能 |
|---|---|
| `AUTODIM` | 逐段標註：直線/聚合線直線段 → 對齊尺寸（自動放外側）、弧 → 半徑、圓 → 直徑，可加總尺寸 |
| `ADIMTOTAL` | 只加整體水平 + 垂直總尺寸 |
| `ACLIST` | 解讀設計意圖：列出偵測到的設計概念（不畫尺寸） |
| `ACDIM` | 依設計概念標註，只標必要尺寸、合併重複特徵 |

## 設計概念標註 (`ACDIM` / `ACLIST`)

參考 Yang & Pan, *Discovering Design Concepts for CAD Sketches*, NeurIPS 2022
([arXiv:2210.14451](https://arxiv.org/abs/2210.14451))。論文把草圖視為「圖元 + 約束」，
並把反覆出現的組合歸納成可重用的**設計概念**，用來解讀設計意圖與自動補全。

本程式用**固定規則的概念庫**（不是論文的神經網路）偵測概念，再依概念標註：

| 概念 | 判斷的約束 | 標註 |
|---|---|---|
| 矩形 | 封閉、4 條直線、相鄰邊垂直 | 長、寬各一個 |
| 正方形 | 矩形且邊長相等 | 一個 `□邊長` |
| 長槽孔 | 直線-半圓-直線-半圓、兩直線等長 | 中心距、槽寬 |
| 正多邊形 | 封閉、等邊、頂點共圓 | 一個 `n×邊長` |
| 孔群 | 相同半徑的圓 | 一個 `n×Ø`；若等距排成一直線，再加 `(n-1)×節距` |
| 相同半徑圓弧 | 半徑相等（含聚合線中的弧段） | 一個 `n×R` |
| 其他 | — | 與 `AUTODIM` 相同的逐段標註 |

## 限制
- 未在每個 AutoCAD 版本實測，請先在測試圖上試用。
- 只處理 LINE、LWPOLYLINE、ARC、CIRCLE，2D、世界座標。
- 孔群不標孔的定位尺寸（相對邊界的位置）。
- 相鄰圖形共用的邊會重複標註。
