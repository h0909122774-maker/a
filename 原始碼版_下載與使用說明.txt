==============================================================
  AutoDim 原始碼版（Python 版）下載與使用說明
==============================================================

原始碼版和 exe 版功能完全一樣，差別只在：
  - 原始碼版要先安裝 Python 才能執行
  - 不需要打包、不需要 C 編譯器，作者準備起來比較簡單
  - 一樣需要授權碼才能使用


【A. 作者（你）：製作原始碼版壓縮檔】
--------------------------------------------------------------
1. 確認 C:\autodim\ 裡有這些檔案：
     autocad_auto_dim.py   licensing.py    ed25519_pure.py
     start_autodim.bat     autodim_toggle.lsp
     使用說明.txt          原始碼版_下載與使用說明.txt
     make_source_zip.bat
   以及已經執行過 keygen.py init（licensing.py 裡有公鑰）。
2. 雙擊 make_source_zip.bat
3. 資料夾裡會出現 AutoDim_source.zip，把這個檔案傳給對方
   （Email、LINE、雲端硬碟、隨身碟都可以）。
   壓縮檔裡不會有 keygen.py 和 private_key.pem。

   注意：GitHub 上的 licensing.py 沒有你的公鑰，
   對方直接從 GitHub 下載的版本無法輸入授權碼使用，
   一定要用 make_source_zip.bat 做出來的壓縮檔。


【B. 使用者：下載與安裝（只要做一次）】
--------------------------------------------------------------
1. 安裝 Python
   - 打開 https://www.python.org/downloads/windows/
   - 在 Python 3.13 那一段，點「Windows installer (64-bit)」下載
   - 執行安裝檔，最下面一定要勾「Add python.exe to PATH」
   - 按「Install Now」，看到 Setup was successful 按 Close

2. 安裝需要的套件
   - 按 Windows 鍵，輸入 cmd，按 Enter 打開命令提示字元
   - 輸入下面這行後按 Enter：
         python -m pip install comtypes

3. 解壓縮程式
   - 在 AutoDim_source.zip 上按右鍵 →「全部解壓縮」
   - 解壓縮到 C:\  （完成後會有 C:\AutoDim\ 資料夾）

4. 在 AutoCAD 載入指令檔
   - 開 AutoCAD，輸入 APPLOAD
   - 選 C:\AutoDim\autodim_toggle.lsp，按「載入」
   - 想每次自動載入：同一個視窗按「啟動程式集」→「加入」這個檔案

5. 取得授權
   - 先開 AutoCAD，再雙擊 C:\AutoDim\start_autodim.bat
   - 第一次會顯示「機器碼」，例如 A1B2-C3D4-E5F6
   - 把機器碼傳給作者，拿到授權碼後貼到「授權碼：」後面按 Enter
   - 之後在這台電腦就不用再輸入


【C. 每天使用】
--------------------------------------------------------------
1. 先打開 AutoCAD
2. 雙擊 C:\AutoDim\start_autodim.bat（黑色視窗不要關）
3. 開圖：整張圖自動標註；畫圖：畫完按 Enter 就自動標註
4. AutoCAD 指令：
     ADOFF   暫停自動標註
     ADON    恢復自動標註
     ADVIEWS 整張圖改成工程圖式標註（孔位置、2XØ4、R5…）
   建議畫零件圖：ADOFF → 畫完 → ADVIEWS
5. 結束：關掉黑色視窗
6. 記得自己存檔

其他功能、參數、常見問題請看「使用說明.txt」。


【D. 常見問題】
--------------------------------------------------------------
Q：'python' 不是內部或外部命令
A：Python 安裝時沒勾 Add python.exe to PATH，重新安裝並勾選。

Q：No module named comtypes
A：在 cmd 執行 python -m pip install comtypes

Q：找不到執行中的 AutoCAD
A：要先開 AutoCAD 再開 start_autodim.bat；AutoCAD LT 不能用。

Q：程式還沒設定公鑰
A：拿到的不是作者用 make_source_zip.bat 做的壓縮檔，請向作者索取。

Q：授權碼不正確
A：確認機器碼和授權碼是同一台電腦的；換電腦要重新申請。
